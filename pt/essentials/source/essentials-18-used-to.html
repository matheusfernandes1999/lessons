📘 O que é Used To?

Used To é uma expressão usada para falar de hábitos ou situações que aconteciam no passado, mas que não acontecem mais.

Estrutura:

  • Sujeito + used to + verbo base

Exemplos:

  • I used to play soccer when I was a child.

  • She used to live in New York.

  • We didn’t use to eat fast food.

Importante:

  • Para frases negativas e perguntas, usa-se did + verbo base (não used).

  • Used to indica algo que é diferente do presente.

🧠 Na prática!

Exemplos:

  • They used to go to the beach every summer.

  • He didn’t use to like vegetables.

  • Did you use to watch cartoons?

  • I used to have long hair.

📖 Texto de Prática

My Childhood Habits

When I was a child, I used to wake up early. I used to play outside with my friends. I didn’t use to like vegetables, but now I do. My brother used to watch a lot of cartoons. Did you use to have any pets?

Perguntas:

  • What did the speaker use to do as a child?

  • Did the speaker use to like vegetables?

  • What about the brother?

  • Identify 3 sentences with used to in the text.

📌 Revisão da Aula

  • Used to fala sobre hábitos ou situações passadas que mudaram.

  • Estrutura afirmativa: used to + verbo base.

  • Negativa e interrogativa usam did + verbo base.
