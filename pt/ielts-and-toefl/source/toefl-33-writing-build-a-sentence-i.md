## Objetivo da aula
**Foco:** a tarefa *Build a Sentence*: você vê uma fala curta de uma conversa e precisa **organizar palavras/blocos** para formar a resposta correta. Exige domínio da **ordem das palavras** em perguntas, negativas, advérbios e expressões de tempo/lugar.
**Ao final da aula você consegue:** montar frases e perguntas simples sem erros de ordem.
**Tarefa verificável:** montar dez frases de nível A2–B1.

## 1. Warm-up (5 min)
O professor fala uma frase com a ordem errada; o aluno fala a versão correta.
- *Always I study in the morning.* → ______
- *Where you live?* → ______
- *She speaks very well English.* → ______
- *I like very much pizza.* → ______
**Revisão da aula 32:** quais são seus 2 ajustes de speaking? Já praticou?

## 2. Vocabulário-chave (4 min)
### A ordem básica
**Sujeito + Verbo + Objeto + Modo + Lugar + Tempo**
> *She* + *reads* + *the news* + *carefully* + *at home* + *every morning*.
### Perguntas
- **Com auxiliar:** (Wh-) + **do/does/did/is/are/can/have** + sujeito + verbo… → *Where **did you** park?*
- **Com be:** *Where **is** the library?*
### Advérbios de frequência
- **Antes do verbo principal:** *I **usually** study at night.*
- **Depois do be:** *She **is always** late.*
- **Depois do 1º auxiliar:** *I **have never** been there.* · *I **can't always** go.*
### Expressões que não se separam
- *very well* (no fim) → *She speaks English very well.*
- *a lot* (no fim) → *I like pizza a lot.*
- *enough* depois do adjetivo → *It's big enough.*

### Pronúncia: perguntas e ritmo
Ouça, compare e repita:
- *Where did you park?* → *WHERE-djə-PARK?*
- *What time does it start?* → *what-TIME-dəz-it-START?*
- *Have you ever been there?* → *ə-vyə-EV-er-bin-THERE?*
**Frase para repetir 3 vezes:**
> What time does the library usually open on Sundays?

## 3. Explicação e modelo (4 min)
### Estratégia para montar
1. Leia a **fala anterior**: a resposta tem que combinar com ela (pergunta? resposta? sugestão?).
2. Encontre o **verbo** (e o auxiliar). Em pergunta, auxiliar vem antes do sujeito.
3. Encontre o **sujeito**.
4. Coloque o resto: objeto → modo → lugar → tempo.
5. **Leia a frase inteira mentalmente.** Soa natural?
### Modelo
**Fala:** *“I can't find the syllabus anywhere.”*
**Blocos:** *post / it / did / online / professor / the / ?*
→ Raciocínio: há *did* + *?* → pergunta no passado. Verbo: *post* (forma base, porque vem depois de *did*). Sujeito: *the professor*.
→ **Did the professor post it online?**

## 4. Prática guiada (10 min)
### 4.1 Troque e fale: perguntas
> **Where** did you **park** **yesterday**?
> → What time / leave / this morning → Why / miss / the lecture → How / get / to campus → Who / talk to / after class

### 4.2 Monte (oral, depois escrito)
1. usually / at / the library / I / study
2. does / the cafeteria / what time / close / ?
3. never / she / late / is
4. been / have / to Canada / you / ever / ?
5. the slides / can / me / send / you / ?

### 4.3 Combine com a fala anterior
**Fala:** *“I have a lot of reading for tomorrow.”* — Qual resposta montar?
a) *help / you / do / want / me / to / ?* → ______
b) *reading / I / like / a lot* → ______
(Qual combina melhor com a fala? Por quê?)

## 5. Tarefa cronometrada: 10 frases (15 min)
**Regras:** 1 minuto por item. Escreva a frase completa. Depois leia em voz alta.
1. **Fala:** “Is the gym open today?” → *closes / it / at / today / six / but*
2. **Fala:** “I missed the meeting.” → *the notes / you / want / do / ?*
3. **Fala:** “Where's Ana?” → *the library / she / probably / is / in*
4. **Fala:** “How was the exam?” → *harder / than / it / was / expected / I*
5. **Fala:** “Can I borrow your charger?” → *I / using / sorry / am / it / now / right*
6. **Fala:** “I'm going to Chile next week.” → *been / ever / you / there / have / before / ?*
7. **Fala:** “The lab is so cold.” → *I / bring / should / a jacket / always*
8. **Fala:** “What did the professor say?” → *the deadline / she / until / Monday / extended*
9. **Fala:** “I don't understand question 3.” → *you / it / explain / can / I / to / ?* (dica: *Can I…*)
10. **Fala:** “Are you coming to the party?” → *I / finish / have / my essay / to / first*
**Acertos:** __/10
**Fala (3 min):** leia as 10 respostas com entonação natural, como se fosse a conversa real (professor faz a primeira fala).

## 7. Homework da semana
Estude **15–20 minutos por dia**.
**Dia 1 — Regras.** Escreva 5 frases com advérbios de frequência em posições diferentes (be, verbo principal, auxiliar).
**Dia 2 — Perguntas.** Escreva 10 perguntas que você faria a um colega de turma no primeiro dia (*Where…, How long…, Have you ever…*).
**Dia 3 — Embaralhe.** Pegue 8 frases de um e-mail em inglês, embaralhe as palavras e no dia seguinte reorganize.
**Dia 4 — Reorganize.** Monte as frases do dia 3 sem olhar o original. Confira.
**Dia 5 — Speaking.** Grave as 10 perguntas do dia 2 com entonação correta.
**Dia 6 — Mini diálogos.** Escreva 5 mini diálogos de 2 falas (fala + resposta) como os da tarefa.
**Dia 7 — Revisão.** Faça o quiz abaixo.
